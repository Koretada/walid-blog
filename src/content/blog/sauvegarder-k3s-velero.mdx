## TL;DR

À compléter : on installe Velero sur K3s, on configure un backend S3, on planifie des
sauvegardes et **surtout** on teste une restauration.

## Pourquoi tester la restauration

Une sauvegarde jamais restaurée n'est pas une sauvegarde. C'est la phrase qu'on lit partout
et qu'on vérifie rarement.

## Installation

```bash
velero install \
  --provider aws \
  --plugins velero/velero-plugin-for-aws:latest \
  --bucket mes-sauvegardes-k3s \
  --backup-location-config region=eu-west-3 \
  --snapshot-location-config region=eu-west-3 \
  --secret-file ./credentials-velero
```
